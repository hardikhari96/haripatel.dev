Full-featured cryptocurrency trading platform built from scratch, enabling users to trade crypto through INR virtual accounts with integrated balance management, withdrawal capabilities, and real-time price calculations.

## Features

- **INR Virtual Account System**: User-specific virtual accounts powered by Hypto for secure INR balance management
- **Withdrawal Capability**: Users can withdraw funds to their bank accounts
- **Admin Controls**: Administrative panel to send crypto to user accounts and manage funds
- **Virtual Balance Management**: Track and manage INR money in virtual accounts per user
- **Master Account**: Centralized master account for balance oversight
- **Multiple Crypto Accounts**: Users can set up and manage multiple cryptocurrency accounts
- **Real-time Price Calculator**: Integrated cryptocurrency price calculator for accurate INR valuations

## Implementation

Built entirely from scratch using core PHP, HTML, Bootstrap, and CSS without relying on frameworks or templates. The platform integrates Hypto's virtual account system for secure INR payment processing and balance management. Each user has their own virtual account to manage Indian Rupees, with capabilities to withdraw funds to their bank accounts. Administrators can distribute cryptocurrency to users, manage virtual INR balances, and users can maintain multiple crypto accounts with live price tracking in INR.

## Technical Architecture

- **Backend**: Core PHP for all server-side logic and business operations
- **Frontend**: HTML and CSS for structure and styling
- **UI Framework**: Bootstrap for responsive design
- **Virtual Accounts**: Hypto integration for INR virtual account management per user
- **Account Management**: Custom virtual account system with INR balance tracking
- **Withdrawal System**: Bank account withdrawal functionality
- **Price Integration**: Real-time cryptocurrency to INR price calculator
- **Admin Panel**: Comprehensive controls for crypto distribution and balance management

## Key Capabilities

- Send cryptocurrency from admin to user accounts

- Withdraw INR to bank accounts
