Comprehensive insurance management platform enabling agents and users to register, create applications, process payments, and manage two insurance products with hospital LMS integration.

## Role & Responsibilities

- **Full-Stack Development**: Designed and developed complete system from scratch
- **Server Management**: Deployed and managed CentOS-based local server infrastructure
- **Database Design**: MySQL database architecture and optimization
- **Mobile Development**: Android development using Java when primary developer was unavailable

## Project Overview

Built a complete insurance product management system handling the entire lifecycle from registration to hospital system integration, supporting multi-product offerings with different premium structures.

## Key Features

### User & Agent Management
- Agent and user registration via mobile app
- Application creation and submission workflow
- Multi-application tracking for agents
- User scheme visibility and management

### Payment Processing
- Online payment gateway integration for application fees
- Manual receipt entry by agents
- Payment verification workflow
- Transaction tracking and reconciliation

### Application Workflow
- Application submission and fee payment
- Admin verification and approval system
- Automatic integration with hospital LMS upon approval
- Benefit activation for approved users

### Product Offerings

**Aashirwad Product**
- Annual premium structure
- Standard insurance benefits
- Hospital network integration

**Krupa Scheme**
- Monthly premium payment model
- Enhanced benefits package
- Flexible payment options
