Multi-tenant SFTP server platform enabling administrators to create isolated user accounts with direct Google Cloud Storage integration.

## Features

### User Management ✓
- Admin interface for creating and managing SFTP users
- Isolated storage directories per user
- User authentication and access control

### File Operations ✓
- Secure file upload via SFTP protocol
- File download capabilities
- User-specific directory isolation

### Google Cloud Integration (In Progress)
- Direct integration with Google Cloud Storage
- Automatic file synchronization from SFTP to cloud storage
- User-configurable cloud credentials

## Architecture

SFTP server with user-isolated directories, admin management console, and planned Google Cloud Storage backend for automatic file synchronization upon upload.

## Status

**Active Development** - Core SFTP functionality and user management complete. Google Cloud Storage integration in progress.

## Technologies

- SFTP Server
- Google Cloud Storage API
- User Authentication & Authorization
- File System Management
